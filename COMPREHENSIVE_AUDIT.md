### 🔴 BUG #4: Stripe Webhook Not Implemented
**File**: `backend/app/api/payments.py` lines 78-83

**Current Code** (STUB ONLY):
```python
@router.post("/webhook")
async def stripe_webhook(request: dict, ...):
    # This would handle payment completion
    # Implementation depends on Stripe webhook configuration
    return {"status": "received"}  # ← DOES NOTHING!
```

**Impact**:
- User pays $30
- Stripe charges successfully
- Backend never knows payment succeeded
- Case remains locked
- User can't download PDFs

**Fix Required**:
```python
@router.post("/webhook")
async def stripe_webhook(request: Request, db: AsyncSession = Depends(get_db)):
    # 1. Verify Stripe signature
    sig = request.headers.get("stripe-signature")
    payload = await request.body()
    event = stripe.Webhook.construct_event(payload, sig, WEBHOOK_SECRET)

    # 2. Handle payment.succeeded event
    if event.type == "checkout.session.completed":
        session = event.data.object
        case_id = session.metadata.case_id

        # 3. Update payment record
        payment.status = "completed"

        # 4. Unlock case downloads
        case.payment_status = "paid"

        # 5. Send email notification
        await email_service.send_payment_confirmation(...)

        await db.commit()
```
